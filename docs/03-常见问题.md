## 安装阶段

### Q: `install.ps1` 说 "EXT 驱动安装失败，返回码 ..."

按可能性排序：

1. **测试签名没生效** —— 你是不是没重启？`bcdedit /enum {current}` 里要看得到 `testsigning Yes`，外观上桌面右下角应有「测试模式」水印。
2. **Secure Boot 还开着** —— Secure Boot 开启时测试签名无法生效。进 BIOS 关掉。
3. **INF 里没有本机 ID** —— 你是不是直接拿别人的 INF 来装？跑 `prepare-kit.ps1` 生成适配本机的版本。
4. **驱动包不完整** —— `1-Driver-APO` 里只有 INF 没有 DLL，或者 `2-Driver-EXT` 只有 INF 没有 CAT。

### Q: 提示 "not compatible" 或安装程序直接退出

你用的是 OEM 原版 RestoreTool，它带硬件白名单校验（`PreInstall.ps1`），会拒绝非目标机型。

**不要用原版 RestoreTool 安装。** 用它解包出文件，然后用本项目的 `prepare-kit.ps1` + `install.ps1`。

### Q: `prepare-kit.ps1` 说 "子系统厂商不是广达"

你的机器不是 Quanta 模具（`SUBSYS` 前四位不是 `152D`）。脚本会问你是否继续 —— **建议停手**。

不同模具的端点拓扑可能完全不同，EXT 驱动里追加的 `InterfaceSetting`（`GeneralRtkEP_1430` / `ThunderobotVNRtkEP_1430`）对不上，装了也不会生效，还可能让音频异常。

### Q: BIOS 里找不到 Secure Boot 选项

- 某些机型藏在 `Security` → `Secure Boot` → `Secure Boot Control`
- 需要先设置 BIOS 管理员密码才能改
- 少数低端模具 BIOS 完全不暴露该选项 —— 这种情况本项目**无法使用**，因为装载不了改签名的驱动

### Q: 装完设备管理器出现黄色感叹号

- 看具体错误码。**代码 52** = 签名校验失败，说明测试签名没生效或 Secure Boot 没关。
- **代码 28** = 驱动文件缺失，`1-Driver-APO` 目录不完整。
- **代码 10** = 设备无法启动，通常是版本冲突，先卸载旧驱动再装。

## 使用阶段

### Q: App 能打开，但调节什么都没效果

APO 没真正进链。检查顺序：

1. 设备管理器 → **软件组件** → 是否有 `A-Volute Nh4 Audio Effects Component`？没有说明 EXT 驱动没绑上。
2. 跑 `dump-apo.ps1`，看当前端点的 `,5` / `,6` 是不是 Nahimic 的 CLSID？如果是空或别的，说明端点没被接管。
3. `NahimicService` 是否在运行？
4. 是否同时装了 Dolby / DTS / Sonic Studio / Sonar？**多个音效引擎会互相顶掉**，只留一个。

### Q: App 一打开就闪退

1. 检查 UWP 依赖是否装全（`Microsoft.NET.Native.Framework.2.2`、`Runtime.2.2`、`VCLibs.140.00`）。
2. 用 DISM 预配方式重装（`install.ps1` 会自动降级到 DISM）。
3. 看事件查看器 → Windows 日志 → 应用程序，找 `Nahimic3.exe` 的错误。

### Q: 声音追踪器只有前方（最常见的问题）

**这是端点能力限制，不是安装失败。** 详见 [02-端点与声音追踪器](02-端点与声音追踪器.md)。

快速判断：跑 `dump-apo.ps1`，如果当前端点是 **2 声道 + 复合链**，就是这个原因，无解。

解决：换 USB 声卡/小尾巴，或改用内置扬声器。

### Q: 插上耳机后音效就没了 / 换设备要重新配

Realtek 的耳机孔和内置扬声器在系统里是**两个独立端点**，各自有独立的 APO 配置。

如果你只在耳机的插着的时候装了，那扬声器端点上可能没挂 Nahimic。反之亦然。

处理：切到目标设备后，重新跑一次 `install.ps1` 的驱动部分（或者让 Nahimic App 重新「优化此设备」）。

### Q: 某个 Windows 更新后突然失效

Windows Update 把 Realtek 驱动换成了不带 APO4 支持的通用版。

处理：

```powershell
# 重跑驱动安装（不需要再开测试签名，已开过）
.\scripts\install.ps1 -KitDir "D:\kit-ready" -SkipAppx
```

然后**暂停驱动更新**：设置 → Windows 更新 → 高级选项 → 可选更新 / 或者用组策略排除驱动更新。

### Q: 游戏反作弊报错 / 游戏启动崩溃

部分反作弊（社区报告集中在 Riot 系：Valorant、LoL）会把音效钩子误判。

处理：

```powershell
Stop-Service NahimicService
# 玩完再开
Start-Service NahimicService
```

如果长期冲突，可以用 `uninstall.ps1` 卸载。

### Q: 和 SteelSeries Sonar 冲突吗

可以共存，但两者都做音效处理，**叠加会让听感互相干扰**（Sonar 的 EQ + Nahimic 的 EQ 串联）。

建议：
- 用 Sonar 时把 Nahimic 的音效预设设成「平直」或关掉
- 对比测试时只开一个
- Sonar 会抢默认设备，切换时注意当前默认是哪个

### Q: 蓝牙耳机上有音效吗

**没有。** 蓝牙音频走完全独立的链路（A2DP / LE Audio），APO 不参与。Nahimic 只作用于本地音频端点。

### Q: 装完 App 里会显示雷神（Thunderobot）的品牌字样吗

**不会。** 实测 App 界面不显示任何 OEM 品牌，和原生 Nahimic 3 一样。

需要说清楚一个容易混淆的点：EXT 驱动确实写了 `PKEY_VENDORNAME = "Thunderobot"`，但它落进的是 **Windows 端点属性**（`{3B454CDE-1938-473F-9DDBF-5D6A56332FB5},0`，每个 Render / Capture 端点下都能查到），**不是 App 的界面字段**。App 识别设备靠的是 `PKEY_PRODUCTID = "A-Volute.Nahimic"`，跟 VendorName 无关。

所以：如果你想改这个字符串（比如设备属性里想显示自己机器的品牌），可以改 EXT INF 里的 `PKEY_VENDORNAME` 再重装驱动；**但不改也没有任何副作用**，App 既不看它，也不会因此选错皮肤。

### Q: 右下角托盘里为什么没有 Nahimic 图标

**因为它本来就基本不出现，这不是装失败。**

Nahimic 3 的托盘图标由独立的小程序 **Nahimic Companion** 提供：

| 项目 | 值 |
|---|---|
| 文件 | `%LOCALAPPDATA%\NhNotifSys\nahimic\nahimicNotifSys.exe` |
| 版本信息 | `A-Volute NS` 1.4.8.0（A-Volute） |
| 作用 | App / 驱动**更新检查与通知**，不是主控制面板 |

它**不会常驻自启动**：没有 `Run` 键、没有计划任务、Appx 清单里也没有 `StartupTask` 扩展。只有 Nahimic 3 应用运行时或需要提示更新时，它才会被拉起来。你可以在注册表 `HKCU\Control Panel\NotifyIconSettings` 里查到它的登记记录（`InitialTooltip = Nahimic Companion`），说明它确实注册过托盘图标，只是平时不常驻。

**不出现反而是好事。** 它的 `NhNotifSys.dll` 里带 `AppUpdater_*` / `DriverUpdater_*` 一整套更新逻辑 —— 一旦它真的弹出来提示更新并执行，会把**打过补丁的 Nahimic 换回官方版本，音效就会失效**。所以不建议去手动启动它。

想打开 Nahimic 控制面板，直接用开始菜单里的 **Nahimic** 应用即可，与托盘无关。

### Q: 计划任务里有两个 NahimicHSSvc32Run / NahimicHSSvc64Run 指向不存在的路径

这是 **Nahimic 官方安装器的残留**，装完就会出现，与本项目的脚本无关。

它们指向安装时解压的临时目录（形如 `C:\Users\<用户>\Downloads\<GUID>\NahimicHSSvc32.exe`），该目录在安装结束后被清理掉了，所以任务永远处于失效状态（`LastTaskResult = 0x41303`，即从未运行）。

**删不删都不影响功能**，因为真正干活的是一对同名任务：`NahimicTask32` / `NahimicTask64`（指向 `system32\NahimicSvc{32,64}.exe`）。只要这两个在跑，音效就正常。

想清理的话，管理员权限下：

```powershell
Unregister-ScheduledTask -TaskName 'NahimicHSSvc32Run','NahimicHSSvc64Run' -Confirm:$false
```

删之前建议先 `Export-ScheduledTask` 备份，随时可 `Register-ScheduledTask -Xml` 还原。

**已实测**（Windows 11 / 隐星 G16 24）：删除这两条失效任务后重启复查，计划任务列表只剩 `NahimicTask32` / `NahimicTask64` 且均为 `Running`，Nahimic 音效、声音追踪器、麦克风降噪全部正常，无任何副作用。

### Q: 桌面右下角一直有「测试模式」水印

测试签名模式的正常现象，**无法在保留驱动的情况下去除**。

要彻底去掉，只能卸载驱动 + `bcdedit /set testsigning off` + 重启。
